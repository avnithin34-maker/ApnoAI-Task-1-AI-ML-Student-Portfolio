# ApnoAI Task 1 — AI & ML Student Portfolio

A simple responsive 4-section website created for the ApnoAI "Ship Your First Web Page" task.

## Sections
- Home
- About
- Services
- Contact

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling

## Run locally
Double-click `index.html`, or open the project folder in VS Code and use any local server extension.

## Deploy
This project can be uploaded directly to GitHub and imported into Vercel.

## Before submission
Replace the example email and social links in `index.html` with your real contact details.
